ListItem is an interactable item thats lives under a ListWidget, under the hood ListItem is just a **Label** having more interactive features like highlighting.

# ListItem::ListItem()

Params:

 - const char* text

Creates an instance of ListItem labelled as the text provided.

# ListItem::setFocused()

Params:

 - bool isFocused;

Fouses and un-focuses the list item.


**Also see ListWidget**
